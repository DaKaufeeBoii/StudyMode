⚡ Formula & Architecture Fast-Vault (Units 1 - 5)

Unit 1: Backprop Gradient Chain Rule

Derivative of loss w.r.t weight $w_{ij}$:

$$\frac{\partial L}{\partial w_{ij}} = \frac{\partial L}{\partial a_j} \cdot \frac{\partial a_j}{\partial z_j} \cdot \frac{\partial z_j}{\partial w_{ij}} = \delta_j \cdot a_i$$

Unit 1: Cross-Entropy Loss

For multi-class classification with $C$ classes:

$$L_{CE} = -\sum_{i=1}^C y_i \log(\hat{y}_i)$$

Unit 2: L1 vs L2 Regularization

L1 induces sparsity; L2 shrinks weights toward zero:

$$J_{L1} = J_0 + \lambda \sum |w_i|, \quad J_{L2} = J_0 + \frac{\lambda}{2} \sum w_i^2$$

Unit 2: Adam Optimizer Updates

Combines Momentum (1st moment) & RMSProp (2nd moment):

$$\hat{m}_t = \frac{m_t}{1 - \beta_1^t}, \quad \hat{v}_t = \frac{v_t}{1 - \beta_2^t}, \quad \theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \hat{m}_t$$

Unit 3: CNN Output Spatial Dimension

Output width/height after convolution:

$$O = \left\lfloor \frac{W - K + 2P}{S} \right\rfloor + 1$$

Unit 3: ResNet Skip Connection

Solves vanishing gradients by identity mapping:

$$\mathbf{y} = \mathcal{F}(\mathbf{x}, \{W_i\}) + \mathbf{x}$$

Unit 4: LSTM Gate Equations

Forget, Input, Candidate, Cell state, Output:

$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$$ $$C_t = f_t \odot C_{t-1} + i_t \odot \tanh(W_c [h_{t-1}, x_t] + b_c)$$ $$h_t = o_t \odot \tanh(C_t)$$

Unit 4: Scaled Dot-Product Attention

Core of Transformers & Self-Attention:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

Unit 5: Autoencoder Loss

Reconstruction error between input $x$ and output $g(f(x))$:

$$L_{AE} = \|x - g(f(x))\|^2$$

Unit 5: GAN Minimax Objective

Two-player zero-sum game between Discriminator and Generator:

$$\min_G \max_D V(D, G) = \mathbb{E}_{x}[\log D(x)] + \mathbb{E}_{z}[\log(1 - D(G(z)))]$$
